 # Taxi Data Analysis

This project performs exploratory data analysis (EDA) and clustering on a taxi trip dataset using Python and Jupyter Notebook.

## Key Work
#### Data loading & inspection (head, info, describe)
#### Data cleaning & preprocessing
#### Outlier detection (Z-score, IQR)
#### Statistical analysis (mean, std)
#### Clustering using KMeans and DBSCAN
## Tech Stack
#### Python
#### Pandas, NumPy
#### Matplotlib, Seaborn
#### Scikit-learn
## How to Run
#### git clone : (https://github.com/ming-lamasherpa/taxi-trip-data-analysis.git)
#### cd taxi-data-analysis
#### pip install -r requirements.txt
#### jupyter notebook
